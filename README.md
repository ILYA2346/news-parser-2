# Как пользоваться сервисом
### Запуск проекта

``` npm i ```
Запустить прокт в одном терминале

``` npm start ```

В другом терминале посылать запрос через curl с ссылкой формата или открывать в браузере ссылку
``` http://localhost:3000/{COUNT}/news/for/{CATEGORY} ```


Пример:

``` http://localhost:3000/3/news/for/business ```
